Putting it on the player

  1. Once: install the firmware with the boot-logo hook.

    It is SinuXVR's custom firmware plus a start-up script and a 4-byte kernel patch that lets it write the logo, built with the script in the xduoo-x3ii-bootlogo project. Copy that update.upt to the root of the SD card, then System settings → Firmware update. Your themes in .themes stay.

  2. Unzip bootlogo.zip to the root of the SD card.

    You should end up with bootlogo/logo.bin on the card, plus boot_animation.png and a shutdown_animation folder if ticked.

  3. Start the player, wait half a minute, restart.

    The first start writes the logo and renames the file to logo.bin.done. Don't switch off during those seconds. The next power-on shows your picture. If not, read bootlogo/flash_log.txt.

To go back: rename bootlogo/original_logo.bin (saved there on the first run) to logo.bin and restart.

Look inside a .bin file

Open any logo file, for example original_logo.bin that the player saves on the card, to see the picture it holds. xDuoo's own logo is grey sparkles with “xDuoo” on black; the screen only makes it look gold during start-up.
